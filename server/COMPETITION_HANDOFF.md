## Owner clarification — professional shooting workflow
- Private audition bytes never serve through the public video endpoint, even after acceptance or publication. Public media uses only official_performances and PRO_VIDEOS with official/ prefix. Staff must record phone contact, invitation, distinct professional recording, rights and moderation approval. Byte-identical uploads are blocked; hash comparison does not prove professional origin, staff must verify independently.
- /basvuru-durumum is a separate private-code status screen. The status endpoint returns invitation date and private invitation note only with the unguessable code. No real invitations sent. Votes are free; each verified account may vote once per official performance (pilot proposed rule). Music clips, social uploads, contracts, events, finals and multi-contest season data are separate future work.
- Schema is a fresh test DB schema only, no migration of an existing database. Pilot age and media limits remain provisional. Both stores must be private and distinct. No actual preview deployment, data collection, storage creation or production release verified.
